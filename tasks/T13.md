# T13 — Test 6: orthographic overlay

**Depends on:** T11 (generator), T03 (source images) · **Parallel with:** T12, T14

## Goal

`tests/test_overlay.py` — the check that catches what the numbers cannot.

## The gap this closes

Every other test in the suite is numeric. Numeric tests cannot detect a layout that is
**dimensionally self-consistent but topologically wrong**:

- A room placed on the wrong side of a corridor
- A mirrored wing
- A door on the wrong wall
- Two rooms of equal area swapped (note: the ground floor has two `Pokój` rooms of
  identical 11.99 m² area — swapping them passes literally every numeric assertion)

Most importantly: the **`(E)` variant mirroring problem.** Archon suffixes denote mirrored
or modified variants. A perfectly-constructed mirror image of the correct house satisfies
every chain sum, every room area, and all five global invariants. This test is the only
thing standing between that and a shipped model.

T03 established the ground truth here: the site's "Pokaż lustrzane odbicie" toggle applies
the flip **client-side via CSS** (`class="has-mirror"`), not by serving a different image.
The bitmaps in `data/source/` are therefore the un-mirrored canonical (E) as served, and
no flip was applied at any stage.

**Orientation anchor** — the generated plan must match this, or the model is mirrored:

| Feature | Position on `plan_ground.png` |
|---|---|
| Wiatrołap (entrance) | bottom, centre-left |
| Kotłownia (boiler room) | bottom right |
| Bedrooms 3 and 5 | left edge |

Assert this anchor programmatically as well as visually — a cheap centroid-quadrant check
on three named rooms catches mirroring even if the image diff is later disabled.

## Method

**Section the actual generated 3D mesh** — do not re-draw the 2D geometry.

```python
# NOT THIS -- `trimesh.Scene` has no `.section()` in trimesh 4.x, and `Trimesh.section()`
# pulls in scipy, which this project does not depend on:
#     section = scene.section(plane_origin=..., plane_normal=...)   # ModuleNotFoundError
#
# Use the pure-numpy primitive per scene node, then polygonise:
from trimesh.intersections import mesh_plane
segments = mesh_plane(mesh, plane_origin=[0, 0, level_z + 1.0], plane_normal=[0, 0, 1])
# then shapely.set_precision(..., 1e-9) BEFORE polygonize -- unsnapped segments
# silently yield no polygon, with no error raised anywhere.
```

Cut at **1.0 m above each floor level**. That height is chosen deliberately: it matches
the PN-70 measurement height, cuts through door openings (so doorways appear as gaps), and
sits below most window sills (so windows appear as solid wall) — which is exactly how a
Polish architectural plan is drawn.

Cutting the real mesh rather than reusing the shapely polygons means this test also
catches **generator** bugs — bad booleans, misplaced extrusions, dropped nodes — not just
spec bugs. That redundancy is the point; do not "optimise" it into a 2D re-render.

## Overlay and diff

1. Raster the section to PNG at a fixed resolution and known scale (matplotlib, fixed
   figure size and DPI, no autoscaling)
2. Align to `data/source/plan_ground.png` / `plan_attic.png` — scale by matching a known
   overall dimension, align by the building's outer corner
3. Produce a three-channel composite: generated in one colour, source in another, overlap
   in a third. Wall lines that do not overlap are immediately visible.
4. Write to `build/overlay_{level}.png`
5. Diff against `tests/golden/overlay_{level}.png`, fail above a pixel-difference threshold

## Human review gate

The first generation of goldens **must be eyeballed by a human before being committed.**
An automatically-accepted golden is worthless — it locks in whatever was wrong at the
time. Make this explicit in the task output: generate the overlays, then stop and ask for
sign-off before writing `tests/golden/`.

After that, the diff runs automatically and only regressions need attention.

## Determinism

Requires T11's deterministic output. Pin matplotlib figure size, DPI, and colours. No
antialiasing variance, no default-style dependence. A flaky overlay test will get disabled
by the next person, which removes the only mirroring guard — so getting determinism right
matters more here than the pixel threshold.

## Acceptance criteria

- Sections cut from the real mesh at 1.0 m above each level
- Composite overlays written for ground and attic
- Human sign-off obtained before goldens are committed
- Diff is stable across repeated runs (run it 3× and confirm zero pixel delta)
- Deliberate test: mirror the spec, confirm the overlay test **fails**. If a mirrored
  model passes, this test does not work and the project has no mirroring defence.
