# T10 — Test 4: topology & sanity

**Depends on:** T07 (geometry kernel) · **Parallel with:** T08, T09

## Goal

`tests/test_topology.py` — cheap assertions that catch structurally impossible geometry.
These do not check *correctness against the source*; they check the model is a coherent
building at all. They run fast and should run before the area tests in CI ordering.

## Checks to implement

### Wall network

- Wall networks form **closed loops** per level — the exterior envelope is a single
  closed ring with no gaps
- No T-junction overshoots (a partition meeting an exterior wall must terminate at it,
  not protrude through it)
- No duplicate walls (two walls with identical or near-identical centrelines)
- No zero-length or sub-50 mm walls (almost always a transcription slip)

### Room polygons

- Every room polygon `is_valid` and is not self-intersecting
- Rooms are mutually **non-overlapping** (`intersection.area < 1e-6` for every pair)
- Union of all room polygons + all wall footprints **==** the exterior footprint polygon,
  within a small tolerance. This is the strongest of these checks: it proves there is no
  unaccounted-for space and no room bleeding outside the envelope.

### Openings

- `offset + width <= wall.length` — every opening fits within its host wall
- Openings on the same wall do not overlap each other
- `sill + height <= ceiling_height` for every opening
- Every opening's `wall` id resolves to an existing wall
- No opening straddles a wall junction

### Completeness against the published table

- Every room in `data/published.json` exists in the spec
- Every room in the spec exists in the published table
- **Both directions.** A one-directional check lets a silently dropped or invented room
  through, and a dropped room is exactly the kind of error that leaves every remaining
  area assertion passing.

### Connectivity

- Every room is reachable from the entrance via doors/passages. A room with no door is
  either a transcription error or genuinely a sealed void — either way it needs a human
  decision, so fail and report rather than skip.

## Note on the union check

The union-equals-footprint assertion needs a tolerance, because wall mitring at corners
produces slivers. Use an area tolerance of ~0.05 m² and report the actual residual — a
growing residual across runs is an early signal that wall joining is degrading.

## Acceptance criteria

- All checks above implemented
- Unit-tested against synthetic broken geometry: an overlapping room pair, an opening
  wider than its wall, an unclosed exterior loop, a room missing from the published table
- Runs in under a second on the full spec (these are the fast checks; keep them fast)
- Failure messages name the specific wall/room/opening ids involved
