# T03 — Source data acquisition

**Depends on:** nothing · **Parallel with:** T01, T02

## Goal

Collect and pin the source material. Everything under `data/source/` is **read-only
evidence** — never edited, never regenerated.

## Deliverables

### 1. Plan images → `data/source/`

From <https://www.archon.pl/projekty-domow/projekt-dom-w-kotewkach-6-e-m3fd297061d375>,
download at the **highest resolution obtainable**:

- Ground floor plan (rzut parteru) with dimension chains → `plan_ground.png`
- Attic plan (rzut poddasza) with dimension chains → `plan_attic.png`
- Elevations (elewacje), all available → `elevation_*.png`
- Section (przekrój) if published → `section.png`
- Site/outline drawing if published → `site.png`

Check for a zoom/lightbox variant serving a larger image than the thumbnail — the
dimension text must be legible enough to read digits unambiguously. **If the printed
dimensions are not legible at the best available resolution, stop and report that**;
it invalidates the entire premise of the approach and is a go/no-go finding.

Record the retrieval date and the exact image URLs in `data/source/PROVENANCE.md`.

### 2. Published figures → `data/published.json`

Machine-readable assertion targets, consumed by T08 and T09. Structure:

```jsonc
{
  "global": {
    "usable_area_m2": 163.57, "net_area_m2": 127.02, "attic_area_m2": 32.88,
    "boiler_room_m2": 7.31, "footprint_m2": 154.42, "floor_area_m2": 222.64,
    "total_area_m2": 307.07, "cubature_m3": 849.27,
    "building_height_m": 7.09, "roof_pitch_deg": 35.0, "roof_area_m2": 216.8,
    "min_plot_m": [25.1, 17.0]
  },
  "rooms": {
    "ground": [ { "name": "Wiatrołap", "area_m2": 5.35 }, ... ],
    "attic":  [ { "name": "Antresola", "area_m2": 14.51 }, ... ]
  },
  "construction": {
    "exterior_wall_layers": [
      { "material": "Porotherm", "thickness_mm": 250 },
      { "material": "EPS Termo Organika", "thickness_mm": 200 }
    ]
  },
  "measurement_norm": null
}
```

Full figures are tabulated in `README.md` — copy them, do not re-derive.

`measurement_norm` is left `null` deliberately; T15 fills it in.

### 3. Verify the reconciliation

Assert in `tests/test_published.py` that the published figures are self-consistent:

```
116.18 + 14.51 + 14.67 + 18.21 == 163.57          # usable area
163.57 − 32.88 − 7.31 + 3.64   == 127.02          # net area incl. stairs
sum(ground rooms)               == 116.18
```

If these fail, the transcription of the published table is wrong — fix it before any
downstream task consumes it.

## Watch for

**The `(E)` variant.** Archon suffixes denote mirrored or otherwise modified versions.
Confirm every downloaded image is for the `(E)` variant specifically, and note it in
`PROVENANCE.md`. Working from base-variant plans produces a perfect mirror image of the
right house that passes every numeric check in the suite except T13.

## Acceptance criteria

- All available plan images present, dimension digits legible
- `data/published.json` validates and the three reconciliation assertions pass
- `PROVENANCE.md` records URLs, retrieval date, and confirmed variant
